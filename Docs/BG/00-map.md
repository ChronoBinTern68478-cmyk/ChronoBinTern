# 00-MAP: Карта на идеята

## 🎯 Едно изречение

ChronoBinTern е хибридна архитектура, която кодира двоична и балансирана троична информация в единно състояние (B, T) чрез 7-тактов темпорален код, базиран на BSD систематиката на Авиженис.

## 🧩 Ядрото (стабилно, документирано)

| Компонент | Същност | Документ |
|---|---|---|
| Двуделен акумулатор | B (4 бита, тегла 8, 4, 2, 1, диапазон −11…+15) + T (3 трита, тегла 9, 3, 1, диапазон −13…+13) | 01-core-concept.md |
| Връзка | T = B − 2, инвариант \|T + 2\| = \|B\| | 01-core-concept.md |
| LUT | 27 реда × 16 бита = 54 байта; всеки ред = 7 микростъпки × 2 бита + padding | 02-lut.md |
| Темпорален код | 7 такта; първи 4 → B (двоични тегла), последни 3 → T (троични тегла) | 03-temporal-code.md |
| Микростъпки | F = +1 (01), R = −1 (11), P = 0 (00); кодът е знакът в допълнение на две | 02-lut.md |
| MPC | 27 позиции, 4 бита + контекст; F → +1, R → −1, P → +1 | 03-temporal-code.md |

## 🏗️ Архитектурата (в процес на проектиране)

```text
RISC-V ядро (главен процесор)
  ├── PC + собствен акумулатор
  ├── Регистров файл (B, T временно)
  └── ALU (4 секции)
        ├── 1. Стандартна двоична
        ├── 2. BSD (add_b, sub_b, neg_b)
        ├── 3. TSD (add_t, sub_t, neg_t)
        └── 4. Хибридна (cmp_bt, xchg_bt) – mod 6 + CRT
                │
                │ ENC / DEC
                ▼
Копроцесор: кодек
  ├── MPC (27 позиции)
  ├── LUT (54 байта)
  └── Акумулатор (B, T) ← „домът" на B и T
```

**Ключово:** B и T живеят в копроцесора. RISC-V ги достъпва само чрез ENC/DEC.

## 📜 Теоретична основа

| Тема | Връзка | Статус |
|---|---|---|
| BSD (Avizienis, 1961) | f/r/p = {−1, 0, +1} – точно BSD цифрите | 📝 За документиране |
| Темпорален BSD | 7 такта = 7 BSD цифри, подредени във времето | 📝 За документиране |
| Пространство на Фок | Директна сума на сектори (двоичен ⊕ троичен ⊕ хибриден) | 🔬 Изследване |
| mod 6 + CRT | mod 2 × mod 3 ≅ mod 6; хибридна аритметика | 🔬 Изследване |
| Закономерност 4-3-2 | Позиции в трите свята: 4 (mod 2), 3 (mod 3), 2 (mod 6) | 📝 За документиране |

## 🎯 Ключови решения (взети)

| # | Решение | Защо |
|---:|---|---|
| 1 | P мести MPC +1 (не спира) | 7-те такта винаги напредват |
| 2 | B и T в копроцесора, не в RISC-V регистри | Изолация на кодека |
| 3 | ENC/DEC са единственият мост | Ясен интерфейс |
| 4 | mod 6 + CRT е за проверка, не за пълна аритметика | Губи 78% информация |
| 5 | Само каноничният LUT има постоянен офсет | T = B − 2 за всички редове |
| 6 | Padding в паметта, не на диска | Пестене на дисково пространство |
