# 01-Core Concept: Двойният акумулатор

## 1. Същност
Акумулаторът е разделен на две секции, които работят 
паралелно в един цикъл:
- Първа секция (Binary Key / Index): 4 позиции с двоични 
  тегла 8, 4, 2, 1. Диапазон: −11…+15.
- Втора секция (Ternary Context / Modifier): 3 позиции 
  с балансирани троични тегла 9, 3, 1 (със знак). 
  Диапазон: −13…+13.

## 2. Разделяне на отговорностите
Двете части НЕ се сумират аритметично. Връзката е:
  B = |T + 2|,  sign = sign(T + 2)
или еквивалентно:
  T = Dec − 2,  B = |Dec|,  Dec ∈ [−11, +15]
Двоичната част дава структурния адрес (ключа).
Троичната част дава знаково-тегловния контекст (модификатора).
Заедно образуват хибриден вектор (B, T), който се съпоставя 
асоциативно чрез 27-редовата LUT.

## 3. Защо точно 4 + 3
- 4 + 4 → 81 T-стойности → 2,34 бита контекст → 
  хибридността се размива (T става много по-голямо от B).
- 4 + 2 → 9 T-стойности → контекстът е отрицателен → 
  невалидно.
- 4 + 3 → 27 = 3³ → 0,755 бита контекст → точната 
  „дробна част“ между 16 и 27.

## 4. Кодиране на микростъпките
Всяка от 7-те позиции е 2-битова микростъпка:
  p = 00  (s = 0,  пауза)
  f = 01  (s = +1, принос +тегло)
  r = 11  (s = −1, принос −тегло)
  10 = резерв
Кодът е знакът в допълнение на две – без декодираща таблица.

## 5. Работен пример
(B = 11, T = +9):
  Проверка: |T + 2| = |11| = 11 = B ✓
  LUT индекс: +11 → ред 22 → микро код: fpff / fpp
  Изпълнение:
    B: 8 + 0 + 2 + 1 = +11
    T: 9 + 0 + 0   = +9

## 6. Защо този модел е мощен
- Елиминиране на излишни битове: знакът се изчислява от T, 
  не се пази на диска (4 бита вместо 7).
- Вградена сигурност: (B, T) извън 27-те валидни двойки → 
  грешка. Без допълнителни контролни битове.
- Пълна обратимост: (B, T) ↔ LUT ред ↔ 7 такта.
