# Доказателство за пълнотата на MSPN

## 1. Обозначения

Нека:

- `n ≥ 1` е броят на битовите позиции.
- `b₀, b₁, ..., bₙ₋₁ ∈ {0, 1}` е входната битова последователност.
- `m₀, m₁, ..., mₙ₋₁ ∈ {r, f, p}` е последователността от микростъпки.
- `Wᵢ = 2^(n−1−i)` е теглото на позиция `i`.
- `s: {r, f, p} → {−1, 0, +1}` е знаковата функция:

  ```text
  s(r) = −1
  s(f) = +1
  s(p) =  0
  ```

Стойността на MSPN за двойка (битове, стъпки) се дефинира така:

```text
V = Σᵢ s(mᵢ) × bᵢ × Wᵢ
```

при следното ограничение:

```text
bᵢ = 1  ⟺  mᵢ ∈ {r, f}
bᵢ = 0  ⟺  mᵢ = p
```

## 2. Формулировка на теоремата

**Теорема (пълнота).** За всяко `n ≥ 1` и всяко цяло число `V`, за което:

```text
|V| ≤ 2ⁿ − 1
```

съществуват:

- битова последователност `b₀..bₙ₋₁ ∈ {0,1}ⁿ`
- последователност от микростъпки `m₀..mₙ₋₁ ∈ {r,f,p}ⁿ`

които удовлетворяват горното ограничение и за които:

```text
V = Σᵢ s(mᵢ) × bᵢ × 2^(n−1−i)
```

## 3. Доказателство

### Случай 1: `V ≥ 0`

Нека B = Bₙ₋₁ Bₙ₋₂ ... B₀ е стандартното n-битово двоично
представяне на V без знак. То съществува, защото 0 ≤ V ≤ 2ⁿ − 1.

Дефинираме:

```text
bᵢ = Bᵢ
mᵢ = f, ако bᵢ = 1
mᵢ = p, ако bᵢ = 0
```

Тогава:

```text
Σᵢ s(mᵢ) × bᵢ × 2^(n−1−i)
  = Σᵢ (за bᵢ = 1) (+1) × 2^(n−1−i)
  = Σᵢ Bᵢ × 2^(n−1−i)
  = V
```

### Случай 2: `V < 0`

Нека W = −V. Тогава 1 ≤ W ≤ 2ⁿ − 1.
Нека B е стандартното n-битово представяне на W.

Дефинираме:

```text
bᵢ = Bᵢ
mᵢ = r, ако bᵢ = 1
mᵢ = p, ако bᵢ = 0
```

Тогава:

```text
Σᵢ s(mᵢ) × bᵢ × 2^(n−1−i)
  = Σᵢ (за bᵢ = 1) (−1) × 2^(n−1−i)
  = −Σᵢ Bᵢ × 2^(n−1−i)
  = −W
  = V
```

Следователно теоремата е доказана.

## 4. Следствия

### 4.1 Диапазон

```text
V ∈ [−(2ⁿ − 1), +(2ⁿ − 1)]
```

Броят на представимите стойности е:

```text
2 × (2ⁿ − 1) + 1 = 2^(n+1) − 1
```

### 4.2 Симетрия

Диапазонът е напълно симетричен спрямо нулата.
За разлика от двоичното допълнение до две, няма асиметрия
(−2^(n−1) спрямо +2^(n−1)−1).

### 4.3 Брой кодирания

Всяка позиция има 3 възможни състояния:

| Състояние | `mᵢ` | `bᵢ` | Принос |
|-----------|------|------|--------|
| Нула      | `p`  | `0`  | `0`    |
| Плюс      | `f`  | `1`  | `+W`   |
| Минус     | `r`  | `1`  | `−W`   |

Общ брой кодирания: 3ⁿ.

При n = 4: 3⁴ = 81 кодирания за 31 стойности → излишество.

### 4.4 Излишество

MSPN е излишкова система: една и съща стойност може да има няколко кодирания.

Пример за V = 1, n = 2:

```text
[0,1] с [p,f]  →  0 + 1 = 1
[1,1] с [f,r]  →  +2 − 1 = 1
```

И двете дават 1. Налице е излишество.

|-----|------------------|-----------|-----------|
| 1   | −1 .. +1         | 3         | 3         |
| 2   | −3 .. +3         | 7         | 9         |
| 4   | −15 .. +15       | 31        | 81        |
| 8   | −255 .. +255     | 511       | 6561      |
| 16  | −65535 .. +65535 | 131071    | 43M       |

## 6. Връзка с BSD

MSPN е математически еквивалентна на двоичното представяне със
знакови цифри (Binary Signed Digit, BSD), въведено от Алгирдас
Авизиенис през 1961 г.

Ако дефинираме:

```text
dᵢ = s(mᵢ) × bᵢ
```

то dᵢ ∈ {−1, 0, +1} и:

```text
V = Σᵢ dᵢ × 2^(n−1−i)
```

Това е точно BSD.

Следователно горното доказателство установява две неща:

- MSPN е пълна — всяка стойност в [−(2ⁿ−1), +(2ⁿ−1)] има кодиране.
- MSPN е еквивалентна на BSD — при dᵢ = s(mᵢ) × bᵢ.

Разликата не е в числовото представяне, а в начина на получаване
на цифрата: при BSD цифрата се съхранява, а при MSPN се извежда
от бит и микростъпка.

## 7. Гранични случаи

### 7.1 `n = 1`

Диапазон: −1 .. +1

Кодирания: 3¹ = 3

| `b` | `m` | `V` |
|-----|-----|-----|
| 0   | `p` | 0   |
| 1   | `f` | +1  |
| 1   | `r` | −1  |

Пълно покритие. ✓

### 7.2 `V = 0`

Единственото кодиране е bᵢ = 0 и mᵢ = p за всички i.
Няма +0 / −0. ✓

### 7.3 `V = 2ⁿ − 1`

```text
bᵢ = 1 за всички i
mᵢ = f за всички i
```

### 7.4 `V = −(2ⁿ − 1)`

```text
bᵢ = 1 за всички i
mᵢ = r за всички i
```

## 8. Проверка на реализацията

### 8.1 Изчерпателен тест за `n = 4`

```rust
#[test]
fn exhaustive_n4() {
    let n = 4;
    for v in -(2i64.pow(n) - 1)..=(2i64.pow(n) - 1) {
        let abs = v.abs() as u64;
        let bits: Vec<u8> = (0..n).rev()
            .map(|i| ((abs >> i) & 1) as u8)
            .collect();
        let steps: Vec<Micro> = bits.iter()
            .map(|&b| {
                if b == 0 { Micro::P }
                else if v >= 0 { Micro::F }
                else { Micro::R }
            })
            .collect();
        assert_eq!(mspn_eval(&bits, &steps), v,
            "failed for V = {}", v);
    }
}
```

### 8.2 Тест със свойства

```rust
use proptest::prelude::*;

proptest! {
    #[test]
    fn mspn_complete(v in -15i64..=15) {
```

## 9. Отворени въпроси

Следните въпроси не са разгледани в доказателството и остават отворени:

- **Канонична форма** — Има ли единствено кодиране с минимален
  брой `r`/`f`?
- **Оптимално кодиране** — Кое кодиране за дадено V минимизира
  броя на микростъпките?
- **Разширение към числа с плаваща запетая** — Как MSPN може да се
  разшири към реални числа?
- **Хардуерна цена** — Каква е разходната цена на ниво логически
  елементи за MSPN акумулатор спрямо суматор с двоично допълнение до две?
- **Сравнение с кодирането на Буут** — Как излишеството на MSPN се
  сравнява със знаковото цифрено кодиране на Буут, използвано в умножители?

## 10. Обобщение

MSPN е пълна за всички n ≥ 1 и всички V в
[−(2ⁿ−1), +(2ⁿ−1)].

- MSPN е симетрична спрямо нулата.
- MSPN е излишкова (3ⁿ кодирания за 2^(n+1)−1 стойности).
- MSPN е математически еквивалентна на BSD (Авизиенис, 1961),
  при dᵢ = s(mᵢ) × bᵢ.
- MSPN се различава от BSD по това, че знакът е кодиран в
  микростъпката, а не в цифрата.
